Day 9: Search Engine Marketing (SEM) & Display Advertising
Search Engine Marketing (SEM) & PPC: Learned how Pay-Per-Click models work where advertisers only pay when a user clicks the ad.
Google Ad Formats & Extensions: Explored Text Ads, Shopping Ads, Local Services Ads, and how to use Sitelink and Callout extensions to boost CTR.
7-Step Campaign Setup Pipeline: Understood setting campaign objectives, budgets, bidding strategies, location targeting, and conversion tracking.
Keyword Match Types & Negative Keywords: Learned Broad, Phrase, and Exact matches along with using negative keywords to save budget.
Ad Rank & Quality Score: Explored how Ad Rank is calculated using Max CPC and Quality Score (Expected CTR, Ad Relevance, and Landing Page Experience).
Google Display Network (GDN): Covered responsive display ads, image policies, and avoiding ad fatigue.
